{{/* Version banner (#25). Two cases, both derived from params + the URL — no hard-coded version strings: - preview: a version that is documented but not released yet. It sits ABOVE latest, so the "older version" wording would be exactly backwards. - older: any other available version that is not latest. */}} {{ with site.Params.versions }} {{ $seg := index (split (strings.TrimPrefix "/" $.RelPermalink) "/") 0 }} {{ $cur := strings.TrimPrefix "v" $seg }} {{ $rest := strings.TrimPrefix (printf "/v%s" $cur) $.RelPermalink }} {{ if and .preview (eq $cur .preview) }}
You're reading the docs for v{{ $cur }}, which isn't released yet. Examples pull the preview image. Go to the current release (v{{ .latest }}) →
{{ else if and (in .available $cur) (ne $cur .latest) }}
You're viewing v{{ $cur }} — an older version. Go to the latest (v{{ .latest }}) →
{{ end }} {{ end }}
